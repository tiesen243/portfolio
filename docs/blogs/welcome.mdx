Hi, I'm **Trần Tiến**, better known online as **Tiesen**.

I'm a developer interested in building software across different layers of the stack, from modern web applications and developer tools to mobile apps, IoT, and embedded systems.

This portfolio is a place to share the things I'm building, the ideas I'm exploring, and the lessons I pick up along the way.

## What I Build

My work mainly revolves around **TypeScript, React, Next.js, React Native, Effect, Python, C/C++, and embedded systems**.

I enjoy working across the stack rather than staying in a single layer. That might mean designing a web application one day, building a type-safe API the next, or working with a microcontroller and hardware interface when a project takes me closer to the physical world.

Some of my projects include **Yuki UI**, a component system based on shadcn/ui; and **Effect TanStack Query**, a library for connecting Effect APIs with TanStack Query.

I also work on smaller open-source projects and experiments, including **vercel.nvim**, a Neovim colorscheme inspired by Vercel's visual style.

## Why I Build

Most of my projects start with curiosity.

I like understanding how things work underneath the abstraction, then turning that understanding into something practical. Sometimes that means building a library, sometimes a complete application, and sometimes just a small experiment to answer a question.

Open source is a big part of that process. Sharing code makes it possible to learn from other developers, get feedback, and leave something useful behind.

This portfolio follows the same idea. It is not only a showcase of finished work, but also a record of the things I am learning and building.

## A Little About Me

I'm currently studying **Computer Engineering Technology at the Industrial University of Ho Chi Minh City**, with interests spanning software engineering, embedded systems, and IoT.

I'm particularly interested in systems where different layers have to work together: hardware, firmware, APIs, applications, and the user experience on top of them.

Outside of traditional software development, I also enjoy Linux, open-source software, experimenting with new technologies, and turning random ideas into projects.

My GitHub probably reflects that better than any formal introduction could.

## What's Next

There is always something new to build.

Some projects become polished products, some stay experiments, and some teach me more through the problems they create than through the features they ship.

That's part of what makes development interesting.

I'll be using this site to document those projects, write about technical problems I encounter, and share things that might be useful to other developers.

Welcome to my portfolio, and thanks for stopping by.

— **Tiesen**
